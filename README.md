# Porsche 911 Turbo S — Apple-Grade Scrollytelling Experience

An Apple-style scrollytelling and bespoke car selling interactive web application built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

Featuring a **30fps sequential image frame deconstruction** hero canvas that smoothly tears down the Porsche 911 Turbo S down to its bare-metal monocoque chassis as you scroll.

## ✨ Features

- **Hero Canvas Scrollytelling**: 180 sequential 30fps frames scrubbed dynamically across a 500vh stage with zero buttons on the hero section.
- **Synchronized Narrative Choreography**: Apple-style typography beats floating and fading with high-precision Framer Motion spring physics.
- **Acoustic Boxer Sound Synthesizer**: Pure Web Audio API simulation of the 3.8L VTG Twin-Turbo Flat-6 boxer engine sound from idle (850 RPM) to 7,200 RPM redline.
- **Porsche Active Aerodynamics (PAA)**: Interactive wind-tunnel simulation switching between Speed, Sport Plus, and Airbrake modes.
- **Cockpit Craftsmanship**: 18-Way Adaptive Sport Seats Plus, 855W Burmester 3D Surround Sound, and customizable Exclusive Manufaktur leather swatches.
- **Telemetry Dominance**: Supercar sprint comparison bars (0–60 in 2.6s) and an interactive 360° G-Force telemetry ring.
- **Bespoke Atelier Configurator**: Live price recalculation for custom paints (GT Silver, Shark Blue, Guards Red, Paint to Sample), forged wheels, and performance packages.
- **Porsche Financial Services Modeler**: Real-time acquisition calculator for Premier Lease, Retail Financing, and Direct Cash.
- **Allocation Concierge**: Limited production slot reservation system with digital certificate generation and confetti fireworks.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Launch Development Server
```bash
npm run dev
# or double-click START_WEBSITE.bat on Windows
```

Visit `http://localhost:3000` in your browser.

### 3. Production Build
```bash
npm run build
```
